# M6

The M6 is a 4G/LTE Mobile WiFi modem which is built on top of a Qualcomm Snapdragon 410 (MSM8916, with MDM8916 modem.) It does not have a screen, but it does have Signal, Wi-Fi and Battery LEDs. It uses a custom Android-based firmware with limited coreutils. More information about this device can be found [here](https://github.com/r1bnc/m6-mifi)

Unlike UZ801 with only two core of the CPU enabled, on M6, all four CPU cores enabled on the stock Android-based firmware, but there is no thermal pad on the SoC, you should consider adding 1 mm thermal pad to help spread the heat on the shielding. There are 384MB of RAM on the SoC, and 4GB of eMMC in the form of an SK Hynix NAND flash chip located external to the SoC.

## Supported bands

You can check your device supported bands written near the battery compartment. Typical bands are LTE Band 1/3/5/8/38/39/40//41.

## Installing

With the device fully booted (i.e. beaming a WiFi network, green Wi-Fi LED, etc.) and plugged into the computer that is performing the installation, run:

```sh
./installer m6
```

Note: The default IP for M6 is typically `192.168.100.1`; if yours differs, use the `--admin-ip` argument to specify it.

## LED modes
| Rayhunter state  | LED indicator       |
| ---------------- | ------------------- |
| Recording        | Signal Green LED solid on  |
| Paused           | Signal (Red)  and (Green) LED off |
| Warning Detected | Signal Red LED solid on    |

Note: Similar to UZ801, the M6 also uses solid LED indicators.

## Obtaining a shell
The M6 supports ADB access by default as non-root.

```sh
adb shell
```

To gain root execute this and proceed to access the shell again.

```sh
setprop service.adb.root 1;busybox killall adbd
```

## Device-specific notes

The installation process works as follows:
1. Activates ADB Root
2. Uses ADB to install rayhunter files and modify the startup script
3. Launches rayhunter daemon automatically

- The M6 does not symlink busybox for some core system utils, for some reason. Please use `busybox <utility_name>`, e.g. `busybox df -h`.
- USB debugging is enabled by default but is not under root.
- The device uses `/system/etc/init.qcom.post_boot.sh` as the main startup script.
